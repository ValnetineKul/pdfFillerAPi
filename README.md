# pdfFiller API

Cookie-сессии, пользователи в Postgres и одна генерация PDF на оплату из ChatPlace.

## Локальный запуск

Из этой папки:

```bash
docker compose up --build
```

API: `http://localhost:8080`

Postgres: `localhost:5432`, база `pdffiller`, пользователь и пароль `pdffiller`.

Локальный тестовый аккаунт создаётся при старте, если заданы `SEED_LOGIN` и `SEED_PASSWORD`. В compose это `anna` / `password1`, с 5 генерациями. Для настоящей оплаты уберите seed.

Фронт на `http://localhost:5173` проксирует вход, выход и списание генерации на этот API. После запуска войдите заново: старая сессия из браузера не является cookie этого сервера.

## Оплата ChatPlace

Клиент платит в Instagram. ChatPlace не присылает вебхук сам: в автоматизации с триггером «Успешная оплата» стоит действие «Внешний запрос». Оно вызывает API. API создаёт аккаунт и отправляет логин с паролем в Instagram-директ этого username.

`POST /api/v1/payments/chatplace`

Заголовок: `X-Webhook-Secret: <CHATPLACE_WEBHOOK_SECRET>`

Тело запроса в ChatPlace:

```json
{
  "paymentId": "",
  "username": "{{ username }}",
  "channel": "instagram",
  "chatId": ""
}
```

Для автоматизации Telegram укажите `"channel": "telegram"`. Подойдут и старые поля `instagramUsername` / `paymentId`. Если `paymentId` пустой, повтор того же запроса в течение 3 минут не начисляет вторую генерацию.

Для отправки нужен `CHATPLACE_API_KEY`: ключ из ChatPlace, Настройки → MCP, с правом записи в чаты. Это не секрет вебхука. После успешной оплаты API ищет Instagram-чат с этим username и отправляет туда логин и пароль. Поле `delivered` в ответе равно `true`, когда сообщение ушло. Instagram принимает такое сообщение только в течение 24 часов после последнего сообщения клиента, поэтому оплата должна проходить в уже открытом директе.

Новый аккаунт создаётся из username. Пароль возвращается один раз, в полях `password` и `message`, и тем же текстом уходит в директ. Следующая оплата того же человека добавляет одну генерацию и не меняет пароль. Повтор того же `paymentId` генерацию не добавляет. `APP_LOGIN_URL` попадает в текст как ссылка для входа.

Скачивание PDF вызывает `POST /api/v1/documents/consume` и списывает одну генерацию. Когда их ноль, скачивание блокируется до следующей оплаты.

Пароли в базе хранятся только как bcrypt-хеш.
